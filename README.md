## 🛍️ Kiosk — storefront platform

Sellers photograph what they're selling and the listing writes itself: upload
a product photo and the title, description and alt text come back drafted,
ready to be corrected and published.

Go and GraphQL on the back, Postgres underneath, React on the front, a single
binary serving both on Google Cloud Run. Anonymous carts, Stripe Checkout with
a signature-verified webhook, and TypeScript types generated from the GraphQL
schema so the client and server can't drift apart.

The README explains the decisions behind it — how money is stored, how orders
keep a record of what was actually bought, and how the storefront query went
from 14 database round trips to 3.

**[→ Live demo](https://kiosk-257903954523.europe-west3.run.app/s/northlight-press)** · **[→ Code](https://github.com/Girolamone/kiosk)**
